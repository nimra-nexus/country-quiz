# Country Quiz

A terminal quiz game in Python. It asks you the capital of random countries and keeps your score. Country data comes live from the REST Countries API.

## Install

1. Install Python 3.
2. Run: `pip install -r requirements.txt`
3. Get a free API key from restcountries.com
4. Create a file named `.env` and put this inside: `API_KEY=your_key_here`

## Run

```
python countries.py
```

## Sample output

```
Welcome to the Country Quiz!

Q1: What is the capital of Abkhazia? Sukhumi
Correct!

Final score: 1 out of 1
```
